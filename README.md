# ssss — Music, Art & Culture Research Skills

这个仓库用于保存面向音乐、艺术、文化、媒体及相关社会科学研究的 Agent Skills。

## 核心 Skill

`music-art-culture-research`

它把人文学科的解释能力和社会科学的研究规范结合起来，强调：

- 明确研究问题与范围
- 优先寻找一手资料和学术研究
- 文献检索、筛选、引用追踪
- 质性与量化方法匹配
- 区分事实、解释与推论
- 证据三角验证
- 记录不确定性、局限和研究空白
- 不编造引用、数据、页码或事实

## 怎么用

在支持 Agent Skills / `SKILL.md` 的 AI coding agent 环境中，把这个仓库作为 skills 来源，并让 agent 使用 `music-art-culture-research`。

最简单的任务提示：

> 使用 music-art-culture-research skill，研究“为什么 1970 年代纽约会形成 Hip-Hop”。要求优先使用学术论文、书籍和一手资料，区分事实与解释，比较不同学者观点，并指出证据不足之处。

## 推荐研究提示词

```text
使用 music-art-culture-research skill。

研究问题：
[写你的问题]

范围：
[时间 / 地区 / 人群 / 作品]

重点：
[音乐 / 艺术 / 文化 / 社会 / 产业 / 技术等]

要求：
- 优先学术论文、学术书籍和一手资料
- 明确搜索与筛选方法
- 比较不同观点
- 区分事实、解释和推论
- 对重要事实给出来源
- 不确定的地方明确说明
- 最后给出研究空白和下一步建议
```

## 注意

Skill 规定的是“怎么研究”，不是自动提供所有数据库访问权限。实际研究效果取决于所使用的 AI agent 能访问哪些网页、学术数据库、档案和其他资料来源。
